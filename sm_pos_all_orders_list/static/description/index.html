POS All Orders Search & List

View past POS orders, search by customer or receipt reference, and choose how many past orders to preload, directly within the running POS session.
Key Features

Flexible Loading Options

Configure POS to load orders of the current session, load all past orders, or load orders of the last 'n' days.

Quick Search

Effortlessly search for any past order using the customer's name, date, or order/receipt reference number.

Ticket Screen Integration

Click the "All Orders" button inside POS Actions menu to open Odoo's native Ticket Screen with pre-filtered synced orders.

How to Access
In the POS main interface, click the Actions button to display remaining control options, then choose the All Orders button.
Option 1: Load Orders of Current Session
Preload and list only the orders that belong to the current active session. Keeps the POS light and focused on the current shift's transactions.
Option 2: Load All Past Orders
Preload all historical orders from the system database. Allows you to search and view any past order, regardless of which session or cashier completed it.
Option 3: Load Orders of Last 'n' Days
Restrict the preloaded historical orders to a specific number of days. Useful for limiting POS memory usage while still maintaining access to recent past orders.
